## Overview

This dissertation addresses the fragmentation in cryptocurrency classification and regulation across Islamic finance contexts. It provides a principled methodology for assessing cryptocurrency Islamic compliance, synthesizes divergent jurisprudential positions, maps regulatory approaches across Islamic jurisdictions, and proposes an institutional framework for cross-jurisdictional regulatory coordination.

**Total Word Count:** ~70,000 words (chapters + appendices)  
**Structure:** 8 chapters + Abstract + 7 Appendices + Table of Contents  
**Research Scope:** 5 Islamic jurisdictions, 4 Islamic jurisprudential authorities, 5-dimensional classification framework

## Key Findings Summary

### 1. Islamic Legal Assessment (Chapter 2)

**Maqasid Shariah Scores:**
- Pure cryptocurrencies: **2.4/5** (fails necessity and certainty requirements)
- Asset-backed alternatives: **4.0-4.5/5** (significantly higher compliance)
- Stablecoins: **4.0/5** (address stability concerns)

**Key Insight:** Cryptocurrency Islamic compliance exists on continuum, not binary halal/haram determination.

### 2. Jurisprudential Convergence (Chapter 3)

**Three Points of Consensus Among Islamic Authorities:**
1. Pure cryptocurrencies are non-compliant with Islamic law
2. Asset-backed digital assets merit serious consideration for compliance
3. Maqasid Shariah provides appropriate assessment framework

**Temporal Evolution:** Positions evolved from 2017 categorical prohibition toward 2024 nuanced acceptance of qualified instruments.

### 3. Regulatory Landscape (Chapter 4)

**Five Distinct Regulatory Approaches:**
- Indonesia (OJK): Commodity classification with consumer protection
- Malaysia (BNM): Digital asset framework with innovation support
- Saudi Arabia (SAMA): Categorical prohibition with CBDC alternative
- UAE (VARA): Progressive licensing with Islamic digital asset support
- Bahrain (CBB): Prudential regulation with risk management focus

**Key Insight:** Fragmentation reflects legitimate policy differentiation, not regulatory error.

### 4. Classification Framework (Chapter 5)

**Five-Dimensional Assessment Model:**
1. **Asset Backing** (Dimension 1): Collateral and productive assets (0-5 points)
2. **Value Stability** (Dimension 2): Price stability relative to reference asset (0-5 points)
3. **Productive Utility** (Dimension 3): Economic activity enablement (0-5 points)
4. **Governance** (Dimension 4): Decentralization and transparency (0-5 points)
5. **Regulatory Recognition** (Dimension 5): Islamic jurisdiction approval (0-5 points)

**Classification Categories:**
- **Category A:** Islamic-Compliant (≥19 points) → HALAL
- **Category B:** Conditional-Compliance (15-19 points) → MUBAH MA'A KARAHAH (Permissible with reservations)
- **Category C:** Problematic (10-14 points) → MAKRUH or HARAM (Disliked to Prohibited)
- **Category D:** Speculative/Non-Compliant (5-9 points) → HARAM (Prohibited)
- **Category E:** CBDC (15-25 points) → HALAL (Approved)

**Case Study Scores:**
- Bitcoin: 13 points (Category C - Problematic)
- Ethereum: 12 points (Category C - Problematic)
- USDC: 19 points (Category B - Conditional-Compliance, pathway to Category A)
- Islamic Digital Asset (Hypothetical): 21 points (Category A - Islamic-Compliant)

### 5. Regulatory Harmonization (Chapter 6)

**IIFRC Institutional Proposal:**
- Inter-Islamic Finance Regulatory Council with 6 core + extended members
- Shariah Advisory Council for independent jurisprudential guidance
- Minimum standards for Category A/B recognition
- Mutual recognition protocol enabling single assessment across jurisdictions
- Three-phase implementation timeline (2025-2030)

**Expected Outcomes:**
- Unified cryptocurrency assessment across Islamic jurisdictions
- Reduced regulatory arbitrage and compliance costs
- Clear pathways for cryptocurrency projects to achieve Islamic compliance
- Progressive regulatory harmonization while preserving jurisdictional sovereignty

## Research Methodology

### Framework and Approach

**Maqasid Shariah Analysis:**
- Operationalizes five Islamic jurisprudential objectives as measurable criteria
- Scores cryptocurrencies against each maqasid using 0-5 point scale
- Provides systematic alternative to binary halal/haram determinations

**Comparative Jurisprudential Analysis:**
- Examines positions from AAOIFI, Dar al-Ifta, Taqi Usmani, MUI Indonesia
- Identifies consensus points and legitimate sources of divergence
- Tracks temporal evolution of Islamic authority positions (2017-2024)

**Regulatory Comparative Study:**
- Maps cryptocurrency regulation across 5 major Islamic jurisdictions
- Identifies policy drivers underlying regulatory differentiation
- Analyzes harmonization opportunities and barriers

**Institutional Design:**
- Proposes IIFRC as coordination mechanism for cross-jurisdictional cooperation
- Develops minimum standards and mutual recognition framework
- Creates implementation roadmap with realistic phasing

## Building the Dissertation (PDF & DOCX)

The compiled `Dissertation_Full.pdf` and `Dissertation_Full.docx` are **generated
artifacts**. Do not hand-edit them — edit the Markdown chapters (prose) or
`build/manifest.json` (structure/order), then rebuild.

### One command

```bash
npm install      # once, installs the pinned toolchain (downloads Chromium)
npm run build    # regenerates BOTH Dissertation_Full.pdf and Dissertation_Full.docx
```

Partial builds: `npm run build:pdf` or `npm run build:docx`.

If your environment blocks npm install scripts (so Puppeteer's Chromium is not
fetched automatically), download it explicitly once:

```bash
npx puppeteer browsers install chrome
```

### What the build does

1. Reads the ordered file list + metadata from [`build/manifest.json`](build/manifest.json)
   (the single source of truth for what goes into the document and in what order).
2. Renders each Markdown file to HTML with `markdown-it`, assigning stable heading
   IDs (`markdown-it-anchor`) and auto-generating a title page and a Table of
   Contents (depth 2).
3. Prints the assembled HTML to PDF via headless Chromium (Puppeteer) using
   [`build/assets/style.css`](build/assets/style.css), and converts the same HTML
   to DOCX via `html-to-docx`.
4. Normalizes embedded timestamps / IDs (PDF via `pdf-lib`, DOCX zip via `fflate`)
   so the same Markdown input produces **byte-identical** outputs on every run.

### Toolchain and pinned versions

| Component | Version | Role |
|-----------|---------|------|
| Node.js | ≥ 18 (built/verified on 24.18.0) | Runtime |
| markdown-it | 14.1.0 | Markdown → HTML |
| markdown-it-anchor | 9.2.0 | Stable heading IDs for the TOC |
| puppeteer | 23.11.1 (bundles Chromium 131.0.6778.204) | HTML → PDF |
| html-to-docx | 1.8.0 | HTML → DOCX |
| pdf-lib | 1.17.1 | PDF metadata normalization + page count |
| fflate | 0.8.2 | DOCX (zip) timestamp normalization |

Exact transitive versions are locked in `package-lock.json`; use `npm ci` for a
reproducible install.

### Current output (as built)

- **`Dissertation_Full.pdf`** — 243 pages, A4
- **`Dissertation_Full.docx`** — matching content, Georgia 11pt
- 16 source sections (Abstract + Chapters 1–8 + Appendices B–G, A8), 157 TOC entries

### Changing what's included

Edit `build/manifest.json` — add, remove, or reorder entries in `sections`, or
change the title/author/date in `metadata`. No other file needs to change.

## Key Concepts and Definitions

### Islamic Legal Terms

- **Maqasid Shariah** (Islamic jurisprudential objectives): Five universal principles for evaluating Islamic compliance
- **Al-Darura** (Necessity): Preservation of life and wealth; financial stability requirement
- **Al-Tahaqquq** (Certainty): Clarity and transparency; eliminates gharar (excessive uncertainty)
- **Al-Maslaha** (Public Interest): Community benefit and economic growth
- **Al-Adl** (Justice): Equal treatment and fairness; prevents exploitation
- **Al-Karamah** (Dignity): Economic participation and financial inclusion
- **Gharar** (Excessive Uncertainty): Prohibited speculative contracts
- **Maysir** (Gambling): Prohibited speculation without underlying utility
- **Riba** (Usury): Prohibited interest-bearing debt

### Cryptocurrency Terms

- **Stablecoin**: Cryptocurrency maintaining fixed value relative to reference asset (e.g., USD)
- **Asset-Backed Cryptocurrency**: Digital asset fully collateralized by productive or commodity reserves
- **CBDC** (Central Bank Digital Currency): Central bank-issued digital currency
- **DeFi** (Decentralized Finance): Blockchain-based financial applications
- **Tokenization**: Converting assets into blockchain-based tokens

### Regulatory Terms

- **AAOIFI**: Accounting and Auditing Organization for Islamic Financial Institutions
- **IFSB**: Islamic Financial Services Board
- **BNM**: Bank Negara Malaysia
- **OJK**: Indonesian Financial Services Authority
- **SAMA**: Saudi Arabian Central Bank
- **VARA**: UAE Virtual Assets Regulatory Authority
- **CBB**: Central Bank of Bahrain
- **MUI**: Majelis Ulama Indonesia (Indonesian Council of Islamic Scholars)
