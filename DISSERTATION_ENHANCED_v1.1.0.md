## Appendix: Five-Dimensional Classification Framework (Quick Reference)

```
DIMENSION 1: ASSET BACKING (0-4 points)
├─ 4 points: 100% backed by real assets or clear productive use
├─ 3 points: Majority backed with some collateral
├─ 2 points: Partial backing or unclear productive use
├─ 1 point: Minimal backing
└─ 0 points: No backing or productive use

DIMENSION 2: VALUE STABILITY (0-4 points)
├─ 4 points: <1% monthly volatility (stablecoin standard)
├─ 3 points: 1-5% monthly volatility
├─ 2 points: 5-15% monthly volatility
├─ 1 point: 15-30% monthly volatility
└─ 0 points: >30% monthly volatility

DIMENSION 3: PRODUCTIVE UTILITY (0-4 points)
├─ 4 points: Clear, measurable economic value creation
├─ 3 points: Established productive use case
├─ 2 points: Emerging or limited productive use
├─ 1 point: Minimal productive utility
└─ 0 points: Speculative only (no productive utility)

DIMENSION 4: GOVERNANCE (0-4 points)
├─ 4 points: Clear ownership, transparent decision-making
├─ 3 points: Identifiable control structure
├─ 2 points: Partial governance clarity
├─ 1 point: Unclear or limited governance
└─ 0 points: Decentralized/no clear governance

DIMENSION 5: REGULATORY RECOGNITION (0-3 points)
├─ 3 points: Licensed and regulated by recognized authority
├─ 2 points: Recognized by one jurisdiction
├─ 1 point: Minimal regulatory recognition
└─ 0 points: No regulatory recognition

TOTAL SCORE: 0-23 POINTS

COMPLIANCE CATEGORIES:
A: 19-23 points = Islamic-Compliant (✅ Recommended)
B: 14-18 points = Conditional Compliance (⚠️ Requires review)
C: 10-13 points = Low Compliance (⚠️ Not recommended)
D: 5-9 points = Non-Compliant (❌ Prohibited)
```
