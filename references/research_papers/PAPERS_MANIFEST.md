## Download Instructions

### For Each New Paper

1. Research and locate the paper using academic databases:
   - Google Scholar (scholar.google.com)
   - ResearchGate
   - Academia.edu
   - University library access
   - Islamic finance research centers (IIFA, Islamic Development Bank)

2. Download PDF file

3. Rename with standardized format: `NN_Descriptive_Title.pdf`
   - Example: `07_CBDC_Islamic_Considerations.pdf`

4. Place in `references/research_papers/` folder

5. Update REFERENCES_INDEX.md with actual file size and author information

6. Commit changes with message:
   ```
   docs: add research paper RP-NN - [Title]
   ```
